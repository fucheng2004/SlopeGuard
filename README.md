# SlopeGuard: Towards Generalizable AI-Generated Image Detection via Radial Spectral Slope Guidance

Cheng Fu, Yiheng Li, Yang Yang, and Wenzheng Liu

[Paper (arXiv)](https://arxiv.org/pdf/2611.22727)

SlopeGuard combines radial spectral slope with visual features from a LoRA-adapted CLIP encoder to improve detection of images from unseen generators.

## Code Release

The code will be released in this repository after the paper is accepted.
